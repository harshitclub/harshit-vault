# Harshit Vault

Personal knowledge management (PKM) vault and digital garden built with Obsidian.

## Overview

This repository serves as a centralized second brain for documentation, engineering roadmaps, study notes, and research.

## Structure

- `.obsidian/`: Appearance configurations, snippets, and interface settings.
- `README.md`: Repository overview and documentation.

## Getting Started

1. Clone this repository to your local machine.
2. Open Obsidian and choose "Open folder as vault".
3. Select this directory to load the notes and custom configuration.
