# Harshit Vault

Personal knowledge management (PKM) vault and digital garden built with Obsidian.

---

## Overview

This repository serves as a centralized second brain for engineering roadmaps, software architecture documentation, research notes, and study logs.

---

## Features

- **Automated & One-Click Git Sync**: Push notes directly to GitHub via the Obsidian ribbon icon, `Alt + G` hotkey, or `Quick-Sync.bat`.
- **Advanced Editing Tools**: Notion-style slash commands (`/`), floating formatting toolbar, interactive markdown tables, Templater, Linter, and Dataview.
- **Modern Minimal Theme**: Sleek typography (Inter, Plus Jakarta Sans, JetBrains Mono), glassmorphism styling, refined callouts, and clean card layouts.
- **Interconnected Graph View**: Interlinked knowledge network linking projects, technical domains, concepts, and developer tools into dynamic constellations.

---

## Repository Structure

All notes are kept cleanly at the root level for streamlined search and fast graph connectivity:

- `Home.md`: Central knowledge hub and Map of Content (MOC).
- `Obsidian Guide.md`: Reference manual for keyboard shortcuts, editing tools, and git sync.
- `Projects.md`: Active and planned engineering initiatives.
- `System Design.md` / `Artificial Intelligence.md` / `Software Architecture.md`: Core domain nodes.
- `Developer Toolkit.md` / `Git Workflow.md` / `Python.md` / `TypeScript.md`: Tooling and stack references.
- `Quick-Sync.bat` / `sync.ps1`: One-click synchronization scripts for Windows.
- `.obsidian/`: Appearance configurations, CSS snippets, community plugins, and graph view presets.

---

## Getting Started

1. Clone this repository to your local machine:
   ```bash
   git clone https://github.com/harshitclub/harshit-vault.git
   ```
2. Open Obsidian and choose **Open folder as vault**.
3. Select this directory. All plugins, hotkeys, theme snippets, and graph presets will load automatically.
4. Open `Home.md` or `Obsidian Guide.md` to begin exploring.
