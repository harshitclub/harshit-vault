# TypeScript

Typed superset of JavaScript providing static type checking, enhanced refactoring, and robust enterprise architecture.

## Primary Uses

- **Obsidian Plugins**: Developing custom plugins and UI extensions for Obsidian.
- **Frontend Applications**: React, Next.js, and modern reactive dashboards.
- **API Services**: Node.js and Bun backend servers with strict type contracts.
