# Autonomous Agents

Systems leveraging language models as central processing units to plan, invoke external tools, maintain state, and solve complex multi-step objectives.

## Key Subsystems

1. **Planning**: Decomposing high-level user tasks into sequential and sub-task graphs.
2. **Memory**:
   - Short-term: In-context conversation history and scratchpads.
   - Long-term: Vector database storage and semantic retrieval.
3. **Tool Execution**: Executing API calls, file mutations, and terminal commands with error recovery.
