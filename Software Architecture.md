# Software Architecture

High-level structuring of software systems, component boundaries, interface contracts, and design patterns.

## Architectural Styles

- **Layered Architecture**: Separation of presentation, business logic, data access, and persistence.
- **Hexagonal (Ports & Adapters)**: Decoupling domain logic from external dependencies, databases, and frameworks.
- **Event-Driven Architecture**: Asynchronous messaging and decoupling via queues and event brokers.
